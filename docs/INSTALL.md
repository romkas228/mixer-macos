# Встановлення Mixer

Потрібні **macOS 26 або новіша** та **Mac з Apple Silicon — M1 або новішим чипом серії M**. Цей пакет не підтримує Intel Mac. Інтерфейс українською.

Mixer поширюється під GNU GPL v3 (`GPL-3.0-only`). Файли LICENSE та NOTICE містяться в ZIP поруч із застосунком; вихідний код — у тому самому релізі GitHub.

## Завантаження й встановлення

1. Відкрий [**Releases** репозиторію Mixer](https://github.com/romkas228/mixer-macos/releases).
2. У **Assets** завантаж `Mixer-ВЕРСІЯ-macOS-arm64.zip`. Архіви **Source code** містять код для розробників; готового застосунку в них немає.
3. Розпакуй ZIP подвійним натисканням у Finder. Перетягни **Mixer.app** у **Програми / Applications**.
4. Відкрий Mixer з папки «Програми». Його іконка з’явиться праворуч у верхній смузі меню. Окремого вікна або іконки в Dock немає.

## Якщо macOS блокує перше відкриття

Mixer підписаний постійним власним сертифікатом і не має нотаризації Apple. macOS може заблокувати перше відкриття.

Якщо ти завантажив Mixer із репозиторію розробника й довіряєш цьому джерелу:

1. Спробуй відкрити застосунок один раз.
2. Відкрий **Системні параметри → Приватність і безпека**.
3. Біля повідомлення про Mixer натисни **«Відкрити попри це» / Open Anyway**, потім підтвердь відкриття у системному вікні.

На Mac організації цей виняток може бути недоступний. Якщо повідомлення стосується пошкодження або шкідливого вмісту, повторно перевір джерело й завантаження. Офіційна інструкція: [Apple — Safely open apps on your Mac](https://support.apple.com/en-us/102445).

## Дозвіл на системний звук

При першому запуску Mixer запитає доступ до системного звуку. Натисни **«Дозволити»**. Доступ потрібен для регулювання гучності й перенаправлення звуку програм; Mixer обробляє звук локально, без запису у файли та передавання мережею.

Якщо запит відхилено:

1. Натисни іконку Mixer → **⚙︎ → «Доступ до системного звуку…»**.
2. Натисни **«Відкрити системні параметри»**.
3. У розділі записування системного звуку ввімкни Mixer, зокрема в списку **«Тільки записування системного звуку»**, якщо він там відображається.
4. Якщо macOS запропонує, заверши та знову відкрий Mixer з папки «Програми».

## Використання

- Запусти музику чи відео, відкрий іконку Mixer та зміни гучність відповідної програми.
- **100%** — початкова гучність, **0%** — тиша. Кнопка динаміка окремо вимикає звук.
- Під повзунком можна вибрати аудіовихід. **«Системний вихід»** слідує за виходом macOS.
- **«Системний звук»** — звуки самої macOS; він показується першим, якщо його аудіопроцес доступний.
- **⚙︎ → «Запускати разом із macOS»** вмикає автозапуск за бажанням.
- Escape, повторне натискання іконки або клік поза панеллю закривають її. Tab переміщує фокус; стрілки змінюють гучність, Shift зі стрілками — більшим кроком.

Програма може з’явитися після початку відтворення й залишатися у списку, поки працюють її аудіопроцеси. Вкладки одного браузера не мають окремих повзунків. Для від’єднаного виходу тимчасово використовується системний; збережений вибір відновлюється після підключення.

## Оновлення

1. У меню **⚙︎ → «Про Mixer»** перевір поточну версію.
2. Завантаж новий ZIP із **Releases** того самого репозиторію.
3. Обери **⚙︎ → «Завершити Mixer»** та розпакуй новий архів.
4. Перетягни новий `Mixer.app` у ту саму папку «Програми» й погодься **замінити** попередній застосунок.
5. Відкрий оновлений Mixer з цієї папки.

Налаштування гучності й виходів зберігаються окремо від застосунку. Нові релізи мають використовувати той самий сертифікат і bundle ID; збереження аудіодозволу вже підтверджено для локального оновлення на Mac розробника. Оновлення завантаженого релізу на іншому Mac ще потребує перевірки. З версії 0.1.16 збережені значення нижче 100% звучать тихіше через нову шкалу гучності.

Оновлення встановлюються вручну. При завершенні Mixer повертає звичайне відтворення програм.

## Перевірка завантаження за бажанням

Завантаж `SHA256SUMS` із того самого релізу поруч із ZIP. У Терміналі перейди в папку із цими двома файлами та виконай:

```sh
shasum -a 256 -c SHA256SUMS
```

Результат **OK** означає, що ZIP відповідає опублікованій контрольній сумі. Це перевірка цілісності завантаження; довіру до джерела та системні перевірки macOS вона не замінює.

## Видалення

Вимкни **«Запускати разом із macOS»**, заверши Mixer та перемісти його з папки «Програми» в Кошик. Драйверів і фонових helper-застосунків Mixer не встановлює. Якщо потрібно повернути всі налаштування звуку до початкових значень перед видаленням, скористайся **⚙︎ → «Скинути налаштування звуку»**.
