# Mixer 0.1.18

Перший попередній реліз нативного мікшера звуку в смузі меню macOS.

**Потрібні macOS 26+ та Mac з Apple Silicon (M1 і новіші). Інтерфейс українською.**

Вихідний код відкритий під **GNU GPL v3 (`GPL-3.0-only`)**. LICENSE і NOTICE додаються до ZIP; відповідний вихідний код має бути доступний у цьому ж релізі через Source code.

Перший pre-release перевірено на Mac розробника. Встановлення завантаженого пакета й оновлення на іншому Mac ще не перевіряли.

Можливості:

- Гучність 0–100% та окреме вимкнення звуку для кожної аудіопрограми.
- Вибір аудіовиходу для кожної програми й відновлення збережених налаштувань.
- «Системний звук» macOS на початку списку.
- Нативна панель із системною прозорістю, світлою й темною темою, клавіатурним керуванням.
- Автозапуск за бажанням через меню налаштувань. У 0.1.18 виправлено недоступність цього пункту.
- Обробка аудіо локально, без запису у файли, передавання мережею та встановлення аудіодрайвера.

Завантаж **`Mixer-0.1.18-macOS-arm64.zip`** із Assets, розпакуй і перемісти Mixer у «Програми». Інструкція встановлення й оновлення — у **`INSTALL.md`**; **`SHA256SUMS`** містить контрольну суму ZIP. Архіви Source code призначені для розробників.

Застосунок підписаний постійним власним сертифікатом без нотаризації Apple. Перше відкриття може потребувати підтвердження у «Приватність і безпека»; порядок описано в `INSTALL.md` і [довідці Apple](https://support.apple.com/en-us/102445). Після відкриття дозволь Mixer доступ до системного звуку.

На 100% Mixer не додає послаблення. Починаючи з 0.1.16, повзунок має сильніше послаблення в середній частині шкали: на 50% приблизно −12 дБ. Збережені відсотки нижче 100% після оновлення зі старіших версій звучатимуть тихіше.

Обмеження: немає окремої гучності вкладок браузера, підсилення понад 100%, surround/bitstream і автоматичного оновлення. При зміні виходу можливе коротке переривання; Bluetooth і AirPlay додають власну затримку. Захищений контент і окремі helper-процеси можуть поводитися інакше залежно від програми.
