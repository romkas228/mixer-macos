# Mixer

<img src="Resources/AppIcon.png" width="96" alt="Іконка Mixer">

Нативний мікшер звуку в смузі меню **macOS 26+**. Окрема гучність і аудіовихід для кожної програми. Swift, AppKit та Core Audio, без сторонніх залежностей.

## Можливості

- Гучність **0–100%**, окреме вимкнення звуку та вибір аудіовиходу для кожної аудіопрограми.
- Збереження налаштувань між запусками; «Системний звук» macOS першим у списку.
- Нативна панель із системною прозорістю, світлою й темною темою та керуванням із клавіатури.
- Автозапуск за бажанням через меню налаштувань.
- Локальна обробка аудіо без запису у файли, передавання мережею й встановлення аудіодрайвера.

**Перший пакет:** Apple Silicon (M1 і новіші), macOS 26+. Інтерфейс українською. Підтримка старіших macOS та Intel не входить до цього релізу.

## Встановлення

Перший реліз готується. Готові пакети будуть у [Releases](https://github.com/romkas228/mixer-macos/releases).

Завантаж `Mixer-ВЕРСІЯ-macOS-arm64.zip` із Assets, розпакуй і перемісти **Mixer.app** у «Програми». Застосунок працює через іконку в смузі меню, без іконки в Dock. Під час першого запуску дозволь доступ до системного звуку.

Збірки підписані постійним власним сертифікатом без нотаризації Apple. Перше відкриття може потребувати підтвердження в «Приватність і безпека». Покрокові інструкції: [встановлення, дозвіл на звук та оновлення](docs/INSTALL.md).

Перший pre-release перевірено на Mac розробника. Встановлення завантаженого пакета та оновлення на іншому Mac ще не перевіряли.

## Використання

Запусти музику чи відео й відкрий Mixer. Повзунок змінює гучність програми, кнопка динаміка вимикає звук, список під повзунком обирає вихід.

**100%** означає початкову амплітуду без додаткового послаблення; **0%** — тишу. Шкала нелінійна: на 50% амплітуда становить 0,25, приблизно −12 дБ. «Системний вихід» слідує за виходом macOS. Після від’єднання конкретного пристрою тимчасово використовується системний вихід; при підключенні збережений вибір відновлюється.

Панель доступна з першого кліку та відкривається поверх поточної програми. Escape, повторне натискання іконки або клік поза панеллю закривають її. Tab / Shift-Tab переміщують фокус; стрілки змінюють гучність на 1 відсотковий пункт, Shift зі стрілками — на 10. Home / End задають 0% / 100%.

Меню **⚙︎** містить автозапуск, повторне підключення аудіо, доступ до системного звуку та скидання налаштувань. Завершення Mixer прибирає його аудіомаршрути й повертає звичайне відтворення програм.

## Збірка з вихідного коду

Потрібні macOS 26+, Swift 6.2+ та Xcode Command Line Tools або Xcode.

```sh
git clone https://github.com/romkas228/mixer-macos.git
cd mixer-macos
./scripts/build.sh
open build/Mixer.app
```

У свіжій копії репозиторію використовується ad-hoc підпис для власної локальної збірки. Для сталої ідентичності між оновленнями можна налаштувати власний сертифікат: [підписування](docs/SIGNING.md). Приватний ключ автора для збірки не потрібен і не входить до репозиторію.

```sh
./scripts/test.sh
./scripts/test-interface.sh
./scripts/test-build.sh
```

Core-перевірки використовують невеликий runner без XCTest. AppKit-перевірки працюють із прихованими тестовими вікнами. Перевірки реального підпису та пакування потребують уже зібраного застосунку й налаштованої постійної identity:

```sh
./scripts/test-signing.sh
./scripts/test-release.sh
./scripts/release.sh
```

Пакування використовує системний Python 3 і стандартні бібліотеки; на комп’ютері користувача Mixer не потребує Python. Архітектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Обмеження

- Гучність вкладок одного браузера окремо не регулюється. Групування helper-процесів і захищений контент залежать від конкретної програми.
- Аудіошлях обробляє стерео Float32; mono-вихід отримує downmix, багатоканальний — перші два канали. Surround/bitstream не підтримуються.
- Зміна виходу, створення маршруту або пробудження можуть спричинити коротке переривання. Bluetooth та AirPlay додають власну затримку.
- Підсилення понад 100%, автоматичне оновлення та старіші macOS залишаються можливими майбутніми етапами.
